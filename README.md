# 🧮 Python Calculator

A simple beginner-friendly calculator built with Python.

This project allows you to perform basic arithmetic operations directly from the terminal.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🚫 Prevents division by zero
- 🔄 Allows multiple calculations
- ❌ Type `q` to quit the calculator
- 🛡️ Handles invalid operations

## 🛠️ Built With

- Python 3

## 📋 Requirements

You only need **Python 3** installed on your computer.

You can check if Python is installed by running:

```bash
python --version
```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/AbuShahma05/python-calculator.git
```

2. Open the project folder:

```bash
cd python-calculator
```

3. Run the calculator:

```bash
python calculator.py
```

## 🎮 How to Use

When you start the calculator, choose an operation:

```text
Choose operation (+, -, *, /) or q to quit:
```

Enter:

- `+` for addition
- `-` for subtraction
- `*` for multiplication
- `/` for division
- `q` to quit

### Example

```text
Choose operation (+, -, *, /) or q to quit: +
Enter first number: 10
Enter second number: 5
Result: 15.0
```

Another example:

```text
Choose operation (+, -, *, /) or q to quit: *
Enter first number: 6
Enter second number: 4
Result: 24.0
```
